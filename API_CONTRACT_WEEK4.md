# Week 4 API Contract --- Expense Tracker & Budget Management

## Purpose

This document defines the fixed communication contract between the
frontend and backend.

Both frontend and backend must follow the same:

-   Endpoint paths
-   HTTP methods
-   Field names
-   Category values
-   Request formats
-   Response formats
-   Error formats

------------------------------------------------------------------------

# Base URL

Local backend:

``` text
http://127.0.0.1:8000
```

Frontend environment variable:

``` env
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
```

------------------------------------------------------------------------

# Authentication

All protected endpoints require:

``` http
Authorization: Bearer <access_token>
```

Unauthorized response:

``` json
{
  "detail": "Invalid or expired token"
}
```

# Expense Object

``` json
{
  "id": 1,
  "user_id": 10,
  "amount": 1200,
  "category": "Food",
  "description": "Lunch with friends",
  "date": "2026-08-01",
  "created_at": "2026-08-01T10:30:00Z",
  "updated_at": "2026-08-01T10:30:00Z"
}
```

  Field         Type     Required        Rules
  ------------- -------- --------------- ----------------------------------
  id            number   Response only   Generated by backend
  user_id       number   Response only   Derived from JWT
  amount        number   Yes             \> 0
  category      string   Yes             Must match predefined categories
  description   string   No              Max 250 characters
  date          string   Yes             YYYY-MM-DD
  created_at    string   Response only   ISO timestamp
  updated_at    string   Response only   ISO timestamp

# Endpoints

## 1. Create Expense

`POST /expenses`

Request:

``` json
{
  "amount":1200,
  "category":"Food",
  "description":"Lunch with friends",
  "date":"2026-08-01"
}
```

Response: **201**

Returns the Expense Object.

------------------------------------------------------------------------

## 2. Get Expenses

`GET /expenses`

Supported query parameters:

-   page
-   limit
-   search
-   category
-   start_date
-   end_date
-   min_amount
-   max_amount
-   sort_by
-   sort_order

Example:

``` text
GET /expenses?page=1&limit=10&category=Food&search=lunch
```

Response:

``` json
{
  "items": [],
  "page": 1,
  "limit": 10,
  "total": 0,
  "total_pages": 1
}
```

Sorting:

-   sort_by: date \| amount \| created_at
-   sort_order: asc \| desc

Default:

-   sort_by=date
-   sort_order=desc

------------------------------------------------------------------------

## 3. Get Expense

`GET /expenses/{expense_id}`

Response: Expense Object

404:

``` json
{
  "detail":"Expense not found"
}
```

------------------------------------------------------------------------

## 4. Update Expense

`PUT /expenses/{expense_id}`

All fields optional, but at least one field required.

Returns updated Expense Object.

------------------------------------------------------------------------

## 5. Delete Expense

`DELETE /expenses/{expense_id}`

``` json
{
  "success": true,
  "message": "Expense deleted successfully"
}
```

# Budget Object

``` json
{
  "id":1,
  "user_id":10,
  "month":8,
  "year":2026,
  "budget_amount":20000,
  "created_at":"2026-08-01T10:30:00Z",
  "updated_at":"2026-08-01T10:30:00Z"
}
```

Rules:

-   month: 1--12
-   year: four digits
-   budget_amount \> 0
-   One budget per user per month/year
-   POST updates existing budget if present

------------------------------------------------------------------------

## 6. Create / Update Budget

`POST /budget`

Returns Budget Object.

## 7. Get Budget

`GET /budget?month=8&year=2026`

404:

``` json
{"detail":"Budget not found"}
```

## 8. Category Breakdown

`GET /expenses/category-breakdown?month=8&year=2026`

``` json
{
  "month":8,
  "year":2026,
  "total_spent":15000,
  "categories":[
    {"category":"Rent","amount":10000,"percentage":66.67},
    {"category":"Food","amount":4000,"percentage":26.67}
  ]
}
```

Always return an array.

------------------------------------------------------------------------

## 9. Monthly Summary

`GET /expenses/monthly-summary?month=8&year=2026`

Returns:

-   total_spent
-   budget
-   remaining
-   budget_usage_percentage
-   expense_count
-   largest_category

If budget does not exist, budget-related fields must be `null`.

# Standard Errors

422:

``` json
{
  "detail":[
    {
      "loc":["body","amount"],
      "msg":"Amount must be greater than 0",
      "type":"value_error"
    }
  ]
}
```

403:

``` json
{
  "detail":"You are not allowed to access this expense"
}
```

------------------------------------------------------------------------

# Integration Rules

-   Dates: YYYY-MM-DD
-   Timestamps: ISO-8601
-   Amounts must be JSON numbers
-   Percentages: 0--100
-   Empty lists return `"items": []`
-   Missing budget values must be `null`
-   Backend derives `user_id` from JWT
-   Frontend must never send `user_id`
-   Backend validates ownership before update/delete
-   Categories must exactly match the predefined list
-   All list endpoints include pagination metadata
-   Analytics endpoints return arrays, not dynamic objects
